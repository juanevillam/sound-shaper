## App Privacy — what to declare

**Do you or your third-party partners collect data from this app?** Yes.
**Is any of it used for tracking?** No — for every type below.

| data type (Apple's name)            | what it is in the app                          | linked to the user | purpose           |
| ----------------------------------- | ---------------------------------------------- | ------------------ | ----------------- |
| Contact Info → Email Address        | the sign-in email (or Apple's relay address)   | Yes                | App Functionality |
| Contact Info → Name                 | the name from sign-in, or the one they set     | Yes                | App Functionality |
| User Content → Photos or Videos     | song artwork and the profile photo             | Yes                | App Functionality |
| User Content → Audio Data           | the MP3s they upload                           | Yes                | App Functionality |
| User Content → Other User Content   | sound titles and subtitles, clips              | Yes                | App Functionality |
| Identifiers → User ID               | the Firebase account id                        | Yes                | App Functionality |
| Usage Data → Product Interaction    | listening time and clips saved, for trophies   | Yes                | App Functionality |
| Diagnostics → Crash Data            | Crashlytics reports                            | **No**             | App Functionality |
| Diagnostics → Other Diagnostic Data | the device, OS and app state on a crash report | **No**             | App Functionality |
| Identifiers → Device ID             | Crashlytics' installation id                   | **No**             | App Functionality |

Not collected: location, contacts, browsing or search history, purchases,
financial info, health, sensitive info, advertising data. There is no
analytics SDK and Crashlytics is never given a user id.

The same table is declared in the app's own privacy manifest
(`ios.privacyManifests` in `app.json`, `NSPrivacyCollectedDataTypes`); a change
to one is a change to the other.

## App Review information

- **Sign-in required:** yes, Sign in with Apple or Google. **No demo account
  is provided:** a reviewer signs in with Sign in with Apple, which needs only
  the device's own Apple Account, and starts with an empty library.
- **Contact:** Juan (`juanesvillamendoza@gmail.com`) — the operator, who can
  answer for the app; Grostify only publishes it.
- **Attachment:** one short MP3 Juan owns outright (made by him, or CC0 with
  its source noted), so the reviewer has something to add. A review device
  has no music in Files, and "pick any MP3" with nothing to pick is how a
  personal locker gets rejected under 2.1 for "unable to test".
- **Notes for the reviewer:**

  ```
  Sound Shaper is a personal music player for MP3 files the person already has. Sign in with Apple to start; the library begins empty. To try it, save the attached ZIP to Files and tap it there to unzip it (App Store Connect does not accept an MP3 attachment), then tap Add Sound and choose Midnight Drive.mp3 — the app reads its title and artwork, then plays it through the shaping graph (Equalizer, Playback Speed, Next Room, Echo under Shape; Clips from the player).

  Content: the app only imports files the person picks from their own device. It does not download, stream or convert media from any third-party service or URL, and has no catalogue. Everything a person adds stays in their own account: there is no sharing, no feed, no discovery and no way to see another person's library, so no one else ever sees it. The terms require people to own or have the right to keep what they add, and give a copyright complaint procedure.

  Account deletion: Settings → your name → Delete Account. It removes the person's files, data and account, and revokes the Sign in with Apple token.

  Sound Shaper is built and operated by Juan Esteban Villa Mendoza and published on the App Store by Grostify LLC.
  ```

- **Export compliance:** `ITSAppUsesNonExemptEncryption` is `false` in
  `app.json`, so App Store Connect does not ask.
